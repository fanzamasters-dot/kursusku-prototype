# KursusKu

Platform belajar teknologi untuk mahasiswa yang ingin meningkatkan kemampuan pemrograman web.

## Praktikum 3 - Kalkulator Biaya Kursus

### Rumus

- Subtotal = Biaya per Peserta × Jumlah Peserta
- Diskon = Subtotal × Persentase Diskon / 100
- Total = Subtotal - Diskon + Biaya Admin

### Contoh Input

- Kursus: Laravel Fundamental
- Biaya per Peserta: Rp 350.000
- Jumlah Peserta: 2
- Diskon: 10%
- Biaya Admin: Rp 25.000

### Expected Total

Rp 655.000
